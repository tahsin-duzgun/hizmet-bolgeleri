TÜRKİYE HİZMET BÖLGELERİ - iPhone / iPad PWA

1. GitHub üzerinde yeni bir PUBLIC repository oluşturun (örnek: hizmet-bolgeleri).
2. Bu klasördeki index.html, sw.js, manifest.webmanifest, harita.webp ve iki icon dosyasını repository kök dizinine yükleyin.
3. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Birkaç dakika sonra Pages adresini Safari ile açın: https://KULLANICI.github.io/hizmet-bolgeleri/
5. Safari > Paylaş > Ana Ekrana Ekle.
6. İlk açılışta internet gerekir. Daha sonra ana ekran simgesinden çevrimdışı kullanılabilir.

NOT: Cihaz istatistikleri localStorage içinde saklanır, farklı cihazlarla otomatik senkronize edilmez. Safari verileri temizlenirse kayıtlar silinebilir. Haritadaki işaretler yaklaşık il merkezi konumlarıdır.
